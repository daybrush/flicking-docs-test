옵션 레시피

일반적인 캐러셀 사용 사례를 위한 바로 사용 가능한 옵션 조합과 자주 하는 실수를 피하는 방법입니다.

권장 패턴​

일반적인 사용 사례를 위한 검증된 구성입니다:

무한 루프 캐러셀​

상품 쇼케이스나 이미지 갤러리 같은 지속적인 브라우징 경험에 적합합니다.

  • JavaScript
  • React
  • Vue3
new Flicking("#carousel", {
  circular: true,
  circularFallback: "linear",
  align: "center",
  moveType: "snap"
});
<Flicking
  circular={true}
  circularFallback="linear"
  align="center"
  moveType="snap">
  {/* 패널 */}
</Flicking>
<Flicking :options="{
  circular: true,
  circularFallback: 'linear',
  align: 'center',
  moveType: 'snap'
}">
  <!-- 패널 -->
</Flicking>

작동 원리:

  • circular: 무한 루프 활성화
  • circularFallback: "linear": 패널이 부족할 때 부드러운 성능 저하
  • align: "center": 활성 패널을 중앙에 배치하여 집중도 향상
  • moveType: "snap": 패널에 스냅하여 명확한 탐색 제공

사용 사례: 상품 캐러셀, 히어로 슬라이더, 후기

바운스가 있는 제한된 갤러리​

사용자가 끝에 도달했음을 알 수 있는 포토 갤러리에 적합합니다.

  • JavaScript
  • React
  • Vue3
new Flicking("#carousel", {
  bound: true,
  bounce: "20%",
  align: "prev",
  moveType: "snap"
});
<Flicking
  bound={true}
  bounce="20%"
  align="prev"
  moveType="snap">
  {/* 패널 */}
</Flicking>
<Flicking :options="{
  bound: true,
  bounce: '20%',
  align: 'prev',
  moveType: 'snap'
}">
  <!-- 패널 -->
</Flicking>

작동 원리:

  • bound: 첫 번째/마지막 패널에서 정지
  • bounce: "20%": 경계에서 시각적 피드백 제공
  • align: "prev": 패널을 왼쪽 정렬하여 공간 활용 극대화
  • moveType: "snap": 패널이 위치에 스냅되도록 보장

사용 사례: 포토 갤러리, 파일 브라우저, 기사 목록

페이지네이션이 있는 자유 스크롤​

타임라인이나 카탈로그 같은 콘텐츠가 많은 수평 레이아웃에 적합합니다.

  • JavaScript
  • React
  • Vue3
new Flicking("#carousel", {
  moveType: "freeScroll",
  bound: true,
  panelsPerView: -1,
  align: "prev"
});
<Flicking
  moveType="freeScroll"
  bound={true}
  panelsPerView={-1}
  align="prev">
  {/* 패널 */}
</Flicking>
<Flicking :options="{
  moveType: 'freeScroll',
  bound: true,
  panelsPerView: -1,
  align: 'prev'
}">
  <!-- 패널 -->
</Flicking>

작동 원리:

  • moveType: "freeScroll": 스냅 없이 부드러운 스크롤
  • bound: 오버스크롤 방지
  • panelsPerView: -1: 보이는 패널 수 자동 계산
  • align: "prev": 자연스러운 왼쪽에서 오른쪽 흐름

사용 사례: 수평 타임라인, 상품 카탈로그, 썸네일 스트립

스냅 카운트 스크롤​

특정 수의 패널만큼 이동하는 제어된 탐색에 적합합니다.

  • JavaScript
  • React
  • Vue3
new Flicking("#carousel", {
  moveType: { type: "snap", count: 2 },
  align: "prev",
  bound: true
});
<Flicking
  moveType={{ type: "snap", count: 2 }}
  align="prev"
  bound={true}>
  {/* 패널 */}
</Flicking>
<Flicking :options="{
  moveType: { type: 'snap', count: 2 },
  align: 'prev',
  bound: true
}">
  <!-- 패널 -->
</Flicking>

작동 원리:

  • moveType: { type: "snap", count: 2 }: 한 번에 2개 패널씩 이동
  • align: "prev": 왼쪽 정렬로 명확한 패널 경계
  • bound: true: 가장자리에서 정지

사용 사례: 그리드 스타일 캐러셀, 다중 항목 탐색, 카테고리 브라우저

적응형 높이 캐러셀​

카드나 후기 같이 높이가 다양한 콘텐츠에 적합합니다.

  • JavaScript
  • React
  • Vue3
new Flicking("#carousel", {
  adaptive: true,
  bound: true,
  align: "center",
  moveType: "snap"
});
<Flicking
  adaptive={true}
  bound={true}
  align="center"
  moveType="snap">
  {/* 다양한 높이의 패널 */}
</Flicking>
<Flicking :options="{
  adaptive: true,
  bound: true,
  align: 'center',
  moveType: 'snap'
}">
  <!-- 다양한 높이의 패널 -->
</Flicking>

작동 원리:

  • adaptive: true: 뷰포트 높이가 활성 패널에 맞춰짐
  • bound: true: 명확한 시작/끝 경계
  • align: "center": 다양한 높이의 콘텐츠를 중앙 배치
  • moveType: "snap": 높이 간 부드러운 전환

사용 사례: 카드 캐러셀, 후기, 기능 쇼케이스

자주 하는 실수​

다음과 같은 빈번한 설정 실수를 피하세요:

1. circular + bound 동시 사용​

// ❌ 잘못됨 - bound가 무시됩니다
{ circular: true, bound: true }

문제: 이 옵션들은 상호 배타적입니다. circular가 우선합니다.

해결 방법: 필요에 따라 하나를 선택하세요:

{ circular: true }  // 무한 루프용
{ bound: true }     // 제한된 탐색용

2. circular 없이 circularFallback 사용​

// ❌ 잘못됨 - circularFallback이 효과 없음
{ circular: false, circularFallback: "bound" }

문제: circularFallback은 circular가 활성화되어 있을 때만 작동합니다.

해결 방법:

{ circular: true, circularFallback: "bound" }

3. circular에 패널 부족​

// ⚠️ 자동으로 폴백됩니다
{ circular: true }
// 2개의 작은 패널만 있고, 뷰포트가 더 큼

문제: circular는 총 패널 크기가 뷰포트 크기 이상이어야 합니다.

해결 방법: 패널을 더 추가하거나, 패널 크기를 늘리거나, 명시적으로 circularFallback을 설정하세요:

{ circular: true, circularFallback: "bound" }
